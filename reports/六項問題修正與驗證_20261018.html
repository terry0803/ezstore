修正與證據

問題修正後行為驗證
1. 預覽卻寫入兩個 Agent 的共用寫入判斷加入查一下、查詢、查看、看看、看一下、預覽、估算、試算、算一下、算算、評估、檢查等唯讀詞；第一個 Agent 明確不執行，議價顧問只試算。60 個第一個 Agent 分類組合、24 個議價顧問組合；Gemini 實測兩種預覽均無新增或修改單據。
2. 失敗副本收到明確更新拒絕時，以最後已確認的 updated_at 版本條件清理本次草稿。資料已變更、已發布或已轉單便不自動刪除。連線逾時、閘道錯誤或回覆格式異常時，保留待確認副本編號與連結，不重送寫入。故障注入涵蓋因子更新、二分法第一次與第三次更新失敗；真實測試資料庫確認清理；另模擬更新已提交但回覆遺失，確認不重送、不盲目刪除。瀏覽器測試以真實 API 確認版本及轉單保護。
3. 清單與表單錯誤客戶、產品、訂單清單顯示讀取錯誤及重新載入按鈕，不再用空清單掩蓋失敗；客戶、產品刪除顯示後端原因；編輯資料尚未載入或失敗時不顯示可提交的空表單。瀏覽器模擬 500／400，驗證提示、重試恢復及資料保留。
4. 失效聊天 session僅辨識明確的 Session not found 404，清除舊 session；使用者再次送出完整指令時建立新對話。告知舊上下文失效，不自動重送改價或複製指令。瀏覽器測試驗證新 session 可繼續、複製指令只送一次；一般 500 不重設有效 session。真實 Agent 缺失 session 回 404 且無寫入。
5. 分頁資訊四個 Handler 與 Service 共用分頁正規化；無效字串、負數、超出每頁上限、整數溢位參數皆不再回傳與實際查詢不同的頁碼。Go 邊界測試；瀏覽器 API 測試四種清單；部署後四個本機 API 再確認 page=0&page_size=999 回 1／20。
6. 台灣單號日期報價單及訂單以台灣 UTC+8 業務日期編號；序號依同一日期的單號前綴計數，包含軟刪除資料，不再依賴資料庫 CURRENT_DATE 或匯入資料的 created_at。Go 測試 UTC 15:59:59／16:00:00、UTC 午夜前及跨年；真實 API 確認報價與訂單的日期前綴。
