## 跟講義不同的地方

- 講義 2.9 不准改 `backend/`、`frontend/`、`mcp_server/`。使用者授權修 bug，現在跟老師的 `09f6588` 有差異，完整清單在 `scripts/check_assignment.py` 的 `USER_FIXES`。這不代表老師同意。`check_assignment.py` 嚴格比對會回報這些差異，加 `--allow-user-fixes` 才通過。
  - backend：報價因子先取到小數 4 位再算，範圍 0.0001 到 9.9999；單價先四捨五入到 2 位再乘數量；利潤率存不下時回中文錯誤；訂單單價取到 2 位、不能是負的，關聯的報價單要屬於同一個客戶。
  - mcp_server：客戶名稱有好幾筆相符時請使用者講完整名稱；客戶和報價單清單讀完所有分頁；報價因子超過 9.9999 在複製之前就擋，不留多的草稿。
  - frontend：報價單表單（換客戶時舊回應不會蓋掉新值、載入失敗會說、選項讀完所有分頁、金額用整數分計算）；Chat 沒收到回覆時提醒先查單據；報價單和訂單詳情頁讀不到、發佈、複製、刪除失敗時顯示原因；四個表單存檔後更新快取，馬上重開不會看到舊值，存檔失敗顯示後端給的原因。
- 報價單 Agent 改價前，多一條唯讀連線到後端（`BACKEND_API`），檢查欄位存得下、商品成本和牌價沒變，才呼叫對應的 MCP 工具。它不寫後端，也不取代二分法。
- 模型：程式預設 `gemini-3.8-flash`（講義指定）。測試用 `gemini-3.1-flash-lite`。10/18 中午 Gemini 額度用完時，另一個工具用本機 Qwen3.5 9B 跑過一輪，那些數字在歷史報告裡。

## 10/18 下午修的

1. **寫入防護擋掉正常的要求。** 報價單 Agent 和議價顧問共用的 `write_intent.py` 太嚴：「可以幫我複製報價單…嗎？」「你好，我要將報價單轉訂單…」「總價調成 8000 元」「請問可以把報價因子改為 1.5 嗎」「這張…請幫我複製一份」這類正常說法，18 句裡有 9 句被當成不是要求，回「這句是在問做法，我沒有執行任何操作」。助教用另一份題庫評分，換個說法就可能被扣分。改成：問做法、描述結果、講已經做完的事、轉述客戶想要的價格才不寫入；客氣的問句、開頭打招呼、轉述的指示照常執行。測試在兩個 Agent 的 `tests/unit/test_review_regressions.py`。
2. **議價顧問轉訂單會永久卡住。** 結果不明的紀錄存在 SQLite、不會過期，連「找不到報價單」這種一定沒寫入的失敗也記進去，重灌 seed 也不會清。改成建訂單之前就失敗的（報價單 Agent 預檢擋下、MCP 回「找不到報價單編號」「找不到資料」）直接解除；後端 400 可能發生在寫入之後，照樣擋。新增管理員指令 `python -m pricing_advisor.journal_cli list|resolve`，有訂單才解除，查不到訂單要加 `--confirmed-no-order-written`。錄影腳本加了開錄前檢查。
3. **補回被還原的修正。** 恢復老師基底時，外部檢查回報的兩個前端問題又回來了：報價單、訂單詳情頁讀不到一直顯示「載入中」；發佈、複製、刪除失敗沒有提示。另外報價因子很低時，後端回資料庫的原始溢位錯誤。三個都補回去，測試在 `frontend/e2e/review-regressions.spec.ts` 和 `backend/services/pricing_factor_validation_test.go`。
4. **報告。** 這頁當入口，舊報告開頭都標成歷史紀錄。可信賴度報告改回 LAB 第 9 節的七點格式。
5. **取消的說法。** Gemini 實測時，議價顧問沒認出「先不要壓價了」是取消，因為動詞後面多了「價」。兩個 Agent 都改成「壓價了」「改價了」「轉單了」也算取消，重跑通過。
6. **小地方。** 後端改成先四捨五入再檢查範圍（9.99994 存成 9.9999，跟 Agent、MCP 一致）；README、`policies.py` 和一個測試檔的換行改回原本的格式（`price_change_impact.py` 的 sha256 有登記，沒動）；`start-homework.ps1` 的 C 槽快照在 Start、Restart 後清掉舊的。

## 10/18 晚上修的（外部檢查第二輪）

使用者貼來 6 個問題，都重現得到，全部修掉：

1. **編輯快取沒更新。** 四個表單存檔後只讓清單重讀，單筆資料的快取（30 秒內有效）還是舊的。存檔後馬上重開編輯頁會看到舊值，再存一次就蓋掉剛才的修改。改成存檔成功就用後端回傳的資料更新快取，詳情頁也跟著是新的。
2. **議價顧問把客氣的請求當成問句。** 「可以幫我把…總價改成 200000 嗎？」「能不能把…轉成訂單？」只試算不執行。改成客氣的字後面直接接「幫我」「把」「將」就照做；「改成 200000 可以嗎？」「如果…呢？」這種問可不可行的還是只試算。
3. **表單錯誤只顯示 HTTP 狀態。** 四個表單都改成顯示後端給的中文原因。
4. **後端接受負單價的訂單。** 單價 −1、數量 2 能建出總價 −2 的訂單。改成存檔前就擋。
5. **訂單能關聯別的客戶的報價單。** 改成存檔前讀報價單，客戶不同就擋。
6. **直接呼叫 MCP 改因子會留下多的草稿。** 因子 10 會先複製再失敗。改成複製之前就檢查範圍。走報價單 Agent 本來就會被預檢擋下。

Gemini 實測時，「能不能把…轉成訂單？」被模型判成只檢查，程式沒有機會照做。改成客氣的請求由程式升級成真的要做；句子裡有「試算」「看看」「檢查」這類只想先看結果的字就不升級。改價照樣要過核准規則，需要核准時只產生申請文字。

第 4、5 點是 10/17 修過、恢復老師基底時被還原的。測試在 `backend/services/order_validation_test.go`、`mcp_server/tests/test_lookup_regressions.py`、`frontend/e2e/review-regressions.spec.ts` 和議價顧問的 `tests/unit/test_review_regressions.py`。
