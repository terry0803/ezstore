副本清理與前端三項修正驗證

2026-10-18｜延伸審查後的修正結果

已修正本輪確認的三項問題，驗證通過並更新本機服務。原有 15 位客戶、20 項產品、12 張報價、10 張訂單的完整 API 資料比對一致。隔離測試服務已停止。

問題修正及驗證
清理副本與轉訂單並行時，誤刪已關聯報價清理交易先取得報價列鎖，再用新的 SQL 查詢快照檢查版本、草稿狀態與訂單關聯。建立及重新連結訂單各測兩種先後順序；已編輯、已發布資料保留，未變更副本仍可清理。
中文輸入法選字 Enter 誤送訊息檢查 composition 狀態、原生 isComposing 與 keyCode 229。測試確認選字及 Shift+Enter 都不送出，組字結束後普通 Enter 恰好送出一次。
背景重新載入覆蓋未儲存編輯客戶、產品、報價表單共用草稿保護。伺服器資料變更時保留草稿、顯示提示並阻止儲存；使用者可明確捨棄草稿載入新版。未編輯表單正常更新，相同資料重讀不重設草稿；客戶／產品背景讀取失敗可重試。

本輪實際執行的檢查

  • 最終前端版本：53 項 Chromium Playwright 測試通過，包含新增 12 項回歸；TypeScript／Vite 建置通過。
  • Go 測試與 go vet 通過。
  • 真實 PostgreSQL：新增 7 項清理測試、既有 7 項並行測試通過。
  • 4 項 MCP 故障注入與 session 不存在時無寫入檢查通過；MCP 35 項、scripts 17 項測試與 4 個子測試通過。
  • 使用者授權修正清單檢查通過。未重跑未修改的 Agent／Advisor 全套測試，未呼叫 Gemini 或本地模型。
  • 正式容器映像 ID 與通過測試的映像一致；完整資料內容比對一致。

範圍與限制

表單保護針對已收到的背景重新載入結果，並非後端全面的多使用者樂觀鎖。輸入法驗證採 Chromium 組字事件測試，未涵蓋所有作業系統輸入法。這些結果確認指定問題及已測情境通過，不代表能證明整個系統永遠沒有 bug。

依使用者授權修改老師原始 backend／frontend 的 bug；與老師基底仍有已記錄差異，授權清單通過不等於老師同意修改。保留既有功能及作業架構。
